# 洗濯表示よみ

服のタグの洗濯表示（取扱い表示）の記号を読んで、洗い方・干し方・アイロンの温度・してよいことを選ぶ1日5問のゲーム。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/sentaku-hyoji/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・好きなだけ）、解いた種類の「覚えること」と全部の記号の早見が見られる「記号帳」があります。
- まちがえても選び直せます。正解すると「なぜ」と出典が出ます。ヒントは「見るところ」→「選び肢を2つにしぼる」の2段です。
- むずかしい問題は、タグ全部（洗濯・漂白・乾燥機・干し方・アイロン・ドライ・ウエット）を毎回組み替えて出すので、同じ問題が続きません。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。記号の形は読み上げでも分かるように、形を言葉にしています（意味は言いません）。

## 中身の出どころ

記号の意味は、次の公的な資料で確かめた内容だけで作っています（日本産業規格 JIS L 0001。温度は2024年8月の改正後）。

- [経済産業省・消費者庁 衣類の新しい「取扱い表示」で上手な洗濯！（パンフレット）](https://www.meti.go.jp/policy/economy/hyojun-kijun/keihatsu/pamphlet/pdf/sentakupanf.pdf)：記号の形（おけ・三角・四角・アイロン・丸）と意味、数字は液温の上限、下の線は弱い・非常に弱い、斜線入りの三角は酸素系だけ、干し方の線と日陰の斜線、P・F・W、並ぶ順番、付記用語
- [経済産業省 衣類の「取扱表示」早見表（令和6年8月改正）](https://www.meti.go.jp/policy/economy/hyojun-kijun/keihatsu/pamphlet/pdf/sentakuhayami.pdf)：乾燥機の排気温度（高温80℃・低温60℃まで）、アイロン 210・160・120℃
- [経済産業省 繊維製品の洗濯表示に関する JIS の改正（2024年8月20日）](https://www.meti.go.jp/press/2024/08/20240820001/20240820001-3r.pdf)：アイロンの温度の変更（200・150・110℃から 210・160・120℃へ）、新しい記号

記号の絵はこのゲームで描いたもので、本物のタグとは線の太さなどがちがうことがあります。形を資料で確かめられなかった記号（30℃の手洗い・スチームなしのアイロン・50℃の洗濯）はまだ出していません。迷ったときは、服のタグと、そばに書かれたことば（付記用語）に従ってください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を Google から読み込むとき（保存した文字を確かめ直すときも）、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
